# Haier на максималках

Игра-инструкция для смартфона: как прокачать Android-телевизор Haier на Google TV.

- **Мир 1** — скрытые возможности, которые включаются пультом.
- **Мир 2** — ИИ-агент (Claude Code или ChatGPT Codex) подключается к телевизору по ADB и настраивает его сам.

Сайт: https://android.alexkyubi.com

## Сборка

Страница — один файл `index.html`, собирается из `src/page.html` и картинок `src/img/`:

```bash
node src/build.js
```
